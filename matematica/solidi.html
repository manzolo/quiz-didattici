Formule Solidi Geometrici

Cubo (lato l)
S.lat = 4·l²     S.tot = 6·l²
V = l³         l = ∛V
l = √(S.lat/4)   l = √(S.tot/6)   l = √A_faccia
Parallelepipedo (a × b × h)
S.lat = 2(a+b)·h    S.tot = S.lat + 2·a·b
V = a·b·h        h = V / (a·b)
h = S.lat / (2(a+b))   h = (S.tot−2ab) / (2(a+b))
Prisma (A_b, p_b, h)
S.lat = p_b·h     S.tot = S.lat + 2·A_b
V = A_b·h       h = V / A_b
h = S.lat / p_b   p_b = S.lat / h   A_b = V / h
Base rombica (diag. d₁, d₂)
A_b = d₁·d₂ / 2
lato = √((d₁/2)² + (d₂/2)²)
